# Woodland layout materials

Generated with the built-in image_gen tool for this layout round. Both are original
environment-only concepts; no unit, portrait, control, card text or game value is
generated. Every composed still retains its **concept** corner label.

- `woodland-top.jpg`: top-down ancient stump repaired with broad irregular oak
  planks, understated end-grain rings, mossy grooves and lichen near the edges;
  warm central light fading to cool dark edges. Edge-to-edge, quiet painterly
  material in an enchanted-forest mood; no objects, interface, borders or text.
  Generated PNG converted to JPEG; used as a masked texture and a perspective quad.
- `foreground.png`: genuine alpha cutout of fern fronds, oak leaves, a mossy branch
  and pale mushrooms, concentrated along the left and bottom edges, with the
  upper-right area transparent. Painterly sage/teal foliage with warm highlights;
  no background, interface or text. The source alpha is preserved. Mirrored corner
  copies overlap scenery and rims, with all interface rectangles protected.

Original tool outputs remain in the session's generated-images directory; these
committed copies are the inputs needed to rebuild the studies.
