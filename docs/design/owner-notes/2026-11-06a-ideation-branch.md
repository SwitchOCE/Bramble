# Owner direction: the ideation branch

Said by the owner in chat on 6 November 2026. The owner asked for the first point to be recorded as a rule.

I want you to make a new branch of the repo called something along the lines of ideation branch. And there should be worktrees and stuff that sits alongside this repo. And the number one thing is that nothing from ideation branch ever gets merged to main without my say-so. Record this as a rule.

In ideation branch, I want agents to make decisions without me. They're fully empowered to just try and make the best version of the game based on what I've said, things that I've said in the past, etc. They can iterate as much as they want. And if multiple reviewers independently agree on the same thing, you should just keep iterating along that branch. Treat it almost like a slash goal.

I want you to create this branch and then create me a session on the Optiplex that can run the branch. Its goal would be to oversee just continuous iterative development until it gets the game to a very good state from a playtesting perspective. It needs to focus on interesting designs and strategic depth. And it needs to get a vanilla version of the game up and running. Don't worry about Battlegrounds' extra mechanics like trinkets and quests, etc. Like dark gifts, Darkmoon Faire, all of that: not needed, not required. I want a vanilla version of the game being developed in ideation branch.

Agents' jobs are to take what we've got now, what's known, and just run with it. Make the best game they can. If something's still up for debate, make a choice, make a decision. It's okay to be inspired by other games. It's okay to deviate from the other games. The goal is to give me something really high quality that I can playtest, almost like it's ready for a release, via the agents' tastes, and that I can just try out and see how far I can get with it. They're going to be given every bit of permissions they need.
