# Owner rule: a golden doubles a keyword's number, never changes how the keyword works

Said in chat on 20 November 2026, answering the Briar balance pitch, which proposed goldens where Hawthorn Warden and The Old Hedge get "Root, twice each fight". Other golden proposals of the same day had Husk Sentry "Molt twice" and lowered Fury on the free-attack Badger goldens.

> I don't think golden should affect keywords. Keywords should just double. Keywords are not parts of the card that double. Something like Guard goldens doubling less well than this: that's okay. There should be cards that have variation in how good their golden is. Not all goldens need to be balanced, but all base cards should be. So, I don't like the idea that Hawthorn Warden returns twice. But other than that, everything else seems good, other than stuff that changes how keywords function on goldens. There are a few other examples of that.

Asked which reading was right, the owner chose: **a golden doubles a keyword's number (Thorns 8 → 16, Fury 1 → 2) but never changes how the keyword works (no "twice each fight", no "Molt twice"). Keywords without a number (Guard) stay as they are.**
