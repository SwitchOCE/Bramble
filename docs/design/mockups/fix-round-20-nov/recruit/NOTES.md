# Recruit-screen "after" mock-ups, fix round 20 Nov 2026

Agent-drawn proposals for the owner. Nothing here is decided. Every page says so.

Open any page from this folder in a browser (it sets its base to `docs/ideation-track-2/mockups/` for the card pieces and art, so it needs the symlinks there). Add `?shot` to see only the 1920 × 1080 stage. PNGs are in the scratchpad: `after/recruit/`.

## What the pages are built from

- `after.js` and `after.css` draw the recruit screen as the build draws it today: positions from the build's code (audit, interaction.md section 8), the build's diamond and shield stat settings, keyword marks, price coins, the sill readouts, cog and Cards button. Each page adds its proposal on top.
- Shared pieces reused by path, not copied: the track's `card.js`, `card.css`, `stage.js`, `stage.css`, and the approved kit's `kit.js` and `kit.css` (coin, keyword marks, keyword pills). `kit/data.js` supplies only the frame geometry (`CARD_DATA`).
- `cards.js` is generated by `make_cards.py` from `src/content/*/units.json`. The approved kit's `data.js` is out of date (tiers and text have changed since 17 Nov), so the cards here come from the live content. Re-run it from the repo root if the content changes.
