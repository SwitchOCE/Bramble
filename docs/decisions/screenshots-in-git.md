We take screenshots of the playable game's main screens (the shop, fights, the sandbox, menus), at both computer and phone size. They're saved with the project so you can flip through them without running the game. We only redo them at milestones, and each redo adds about 3 MB.

**What we need from you:** keep saving them with the project, or keep them out?

**Why it matters:** it's a small cost in storage against being able to see how the game looked at each milestone.

We'd suggest keeping them. At about 3 MB a milestone it stays small, and they're handy on the phone.
