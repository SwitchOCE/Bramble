# Hedgerow A2 evidence

The retained `hedgerow-lines.jsonl` is the compact source for growth, accounting, route telemetry and splash. `hedgerow-summary.json` and the test/measurement summaries remain committed. Growth uncertainty for these old runs is in `../potluck-route/growth-intervals.json` under `hedgerow`.

The raw `hedgerow-fights.jsonl.gz`, `hedgerow-players.csv`, `hedgerow-rounds.csv` and `hedgerow-cards.csv` were removed from git after copying them to `build/wave2b/hedgerow/archive-a2/` locally. Rerun captures/CSVs likewise stay in `build/` (or workflow artifacts), not git.
