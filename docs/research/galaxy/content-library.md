# Once Upon a Galaxy: content library

An overview of every Galaxy card in the official database. The full data:
- [data/cards.json](data/cards.json): complete records, including a `wiki` cross-reference.
- [data/cards.csv](data/cards.csv): one row per card.
- [data/card-list.md](data/card-list.md): a readable table of every card.

All three are generated by `tools/research/build_galaxy_library.py`.

## Source and how to rebuild

**Primary source: the official Galaxy Guide card database** at https://guide.galaxy.fun/cards/, run by Million Dreams Games.
- The list page embeds structured attributes for every card: name, type, factions, rules text, rarity, set, pool, token and inactive flags, and the internal card id.
- Each card's own page adds Attack/Health and the set name.
- No API key or login is needed.

**Secondary source: the community wiki** at https://onceuponagalaxy.wiki.gg, read through its MediaWiki API.
- It adds **Golden ability text**. The guide shows Golden versions only as images.
- It also adds the wiki's own stats, so the two sources can be compared.

**Rebuild** (standard library only):
```
python -I tools/research/build_galaxy_library.py            # uses the cache
python -I tools/research/build_galaxy_library.py --refresh  # re-downloads everything
python -I tools/research/build_galaxy_library.py --no-wiki  # skip the wiki pass
```
- Raw downloads are cached in `tools/research/.cache/galaxy/`, which `.gitignore` excludes.
- A first full download takes about 25 minutes: 700 card pages at roughly 2 s each, including a polite delay.

## Coverage

Built 27 Oct 2026 from the live database (Chromaria set plus the 22 Oct 2026 shared-pool patch).

| Type | Current | Removed (inactive) | Total |
|---|---|---|---|
| Characters | 326 | 18 | 344 |
| Treasures (incl. Boons) | 172 | 3 | 175 |
| Captains (incl. prophecy and token captains) | 115 | 1 | 116 |
| Spells | 62 | 1 | 63 |
| **All** | **675** | **23** | **698** |

- **Stats.** Attack/Health was captured for all 344 characters.
- **Wiki match.** 626 of 698 cards matched a wiki page by name.
  - 200 of them have wiki Golden text. Treat it as possibly stale: the wiki's edit dates are stored per card, and many pages were last edited in Sep 2025.
  - 24 cards have wiki stats that differ from the guide (flag `wiki.stats_differ`). I spot-checked one: the gap matched a later balance patch. That case: Puck's support is "+2 Attack" in the guide; the wiki still has the pre-March-2026 "+3". **The guide is authoritative.**
- **What is missing.**
  - Cards cut before the database existed, and old names (about 37 renames in July 2024 alone; see [patch-history.md](patch-history.md)).
  - About 20 wiki-only entries, mostly old or token items: Jack Sparrow, Caesar, Baby Dragon, the Warp Core +1…+6 tokens, Limit Breaker, Robin Hood's Bow and others. These are not in the JSON.
  - "Removed" means only "inactive in the current guide". Inactive cards often rotate back.
- **Ambiguity.** A few captain entries are token or prophecy captains (pool `token`) and can't be picked at captain select.

- Shop-phase triggers dominate: Recruit, Quest and the treasure terms.

## Method notes

- **Keyword tagging** is a case-insensitive whole-word regex over the rules text. It can over-count verbs, for example "summon" inside other text.
- **Silver and Golden stats** come from the guide's own card viewer script, which adds +1/+1 for Silver and +2/+2 for Golden. That matches the guide's Silver and Golden pages and the wiki's stat columns.
- **Golden ability text** comes only from the wiki. Check it against the guide's Golden card images before relying on it.
