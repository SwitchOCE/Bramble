# Counter Display Notes (neon)

**A. Stained-Glass Medallions & Aura Seal (Recommended)**
Lit leaded medallions float on the moss column: stacked hex = clickable heap, roundel = level, with lower-right ivory pills widening for 3-digit numbers. Caps the main grid at four stable slots, routing extras into overflow beads on the anchored Aura plate; Refresh gets an upper-right slate diamond.

**B. The Riveted Slate Tally**
Shows up to six counters live as right-aligned tally rows on `l1z-board.png`: raised green drawer row + chevron for heaps, flush pip ticks for levels. Refresh pairs a lit pip arc with an upper-right numeral clasp.

**C. Mini-Lancet Glass Tray**
Pointed leaded arches with full-width numeral sills fit six counters live in a compact 3×2 tray leaving half the column clear (or dockable on the oak table flank). Refresh uses a leaded `×N` bookmark tag.

**Pick: A.** Matches Bramble's card and portrait grammar, keeps counter positions stable past four, and lets the moss window breathe.

**Unsolved:** Reading counters 5–6 live without clicking Auras (the trade-off for four stable slots). Motion, change-pulse timing, and hover feel are not judged from stills.
