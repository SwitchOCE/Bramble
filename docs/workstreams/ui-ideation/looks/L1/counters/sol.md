# Buy screen counters

**Four plates.** Up to four icon–number plates sit below the portrait, with the highest priority first. Compost has a chevron into its heap.  
The fixed All auras button shows how many counters are off the rail and opens a list of every counter and passive effect.

**Focus pane.** One large glass pane holds the highest-priority counter.  
The same All auras button opens everything else. Paint a bevelled lead frame with a dark central pane if this option goes forward.

**Pick.** Four plates keep two or more values visible together during a purchase. Keep slots steady through value changes and briefly outline the changed plate. Use a two-line refresh face with the count under the loop. Keep the price on the overlapping gold coin.

**Open.** The game still needs a way to rank counters when several matter equally. Slate frames and example icons are provisional. Motion and hover feel were not judged.
