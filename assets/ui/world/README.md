# Shared woodland world

`recruit_backdrop.jpg` and `fight_backdrop.jpg` are the only runtime backdrop paths.
Both copy the art worker's Highcrown Canopy recruit/fight paintings from the
`ui-unit-art` worktree, with cream light from the upper right and cool dark corners. The background fills the window with a centred
cover crop. `stump.jpg` and the alpha-preserving `foreground.png` copy the original
generated materials in `tools/mockup/art/` (see its provenance README).
