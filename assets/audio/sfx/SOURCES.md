# Bramble Sound Sources & Licences

Every sound effect in `assets/audio/sfx/` is built strictly from **CC0 1.0 Universal (Public Domain)** recorded foley samples layered with original procedural DSP generated by scripts in `tools/sound/`. No reference audio from other games is ever loaded, copied, or sampled.

Reproduce all combat hit files deterministically:

```bash
/data/sound-tools/venv/bin/python tools/sound/generate_hits.py
```
